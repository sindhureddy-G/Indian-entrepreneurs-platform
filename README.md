# Web-Based Platform Showcasing Indian Entrepreneurs

An interactive web platform showcasing Indian entrepreneurs and their educational journeys across different states using an India map interface.

## Features
- Interactive India map
- Entrepreneur profile display
- Responsive web design
- User-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Overview
This project was developed to present entrepreneur information in an engaging and interactive way using front-end web technologies.
